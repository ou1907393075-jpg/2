# 修仙模拟人生文字游戏（高自由度 + 战斗深化版）

这是一个命令行修仙模拟游戏，你可以在多个地点自由行动，和大量 NPC 建立关系、接任务、切磋、交易、打探情报，并在动态变化的修真世界中成长。

## 先说最简单：怎么安装 / 运行

你下载下来的确是源码，不是现成安装包。可以按下面 2 条路线走：

### 路线 A：直接运行源码（最快）

1. 安装 Python 3  
2. 进入项目目录运行：

```bash
python3 game.py
```

如果你不想记命令，也可以直接双击：

- macOS / Linux：`install_and_run.sh`
- Windows：`install_and_run.bat`

> 你问“点哪个 BAT？”：  
> - **源码目录里**点 `install_and_run.bat`  
> - **打包后的 zip 解压目录里**点 `start.bat`

### Windows 常见报错（黑框乱码、`'on' 不是内部或外部命令`）

这通常是 `.bat` 文件被错误编码（例如 UTF-8 BOM + 中文）导致 `cmd` 解析异常。  
本仓库现在已改为 **纯英文 ASCII 启动脚本** 来避免该问题。  
如果你还是遇到同类报错，请：

1. 重新拉取最新代码/重新解压最新打包文件  
2. 只运行 `install_and_run.bat` 或 `start.bat`  
3. 不要在压缩包内部直接双击运行（先解压）  

### 路线 B：打包成可分发文件

- 通用 zip（需要目标机器有 Python）：

```bash
python3 build_package.py
```

- Windows 无需 Python 的 EXE（推荐发给普通玩家）：

```bash
pip install pyinstaller
python build_windows_exe.py
```

## 下载与打包说明（无二进制入库）

当前仓库**不提交二进制产物**（如 `.zip`），避免平台兼容/审查问题。你可以在本地一键打包：

```bash
python3 build_package.py
```

打包后会生成：

- `dist/xianxia-game.zip`

解压后运行：

- macOS / Linux：`start.sh`
- Windows：`start.bat`

> 需要本机已安装 Python 3。

## Windows 无需 Python 的可执行版（推荐给普通玩家）

如果你希望在 Windows 上“下载即玩”（不装 Python），请在 Windows 机器上先执行一次：

```bash
pip install pyinstaller
python build_windows_exe.py
```

完成后会生成：

- `dist_windows/xianxia-game-windows-exe.zip`

解压后双击 `xianxia_game.exe` 即可运行。

## 开发运行

```bash
python3 game.py
```

## 继续深化后的特色

- **高自由度行动**：修炼、云游、猎妖战斗、社交、入宗门、休整、任务提交、坊市采购。  
- **活生生 NPC 生态**：NPC 拥有职业、阵营、个性、境界、心情与寿命，会迁徙、结伴、冲突、坐化、新人补位。  
- **任务系统**：可在 NPC 互动中接取任务（历练/社交/修炼），推进进度并提交领奖。  
- **因果系统**：行为会改变因果值，触发善缘顿悟或心魔反噬事件。  
- **战斗系统深化**：加入真气、技能、暴击、防御、逃跑、战斗内吃药机制；支持猎妖战与 NPC 切磋战。  
- **非模板战斗叙事**：每只妖兽都有独立经历与性情；高好感队友会自主参战并独立决策，不受主角直接操控。  
- **队伍系统**：高好感 NPC 可邀请入队，但战斗中会按自身性格和状态自动行动，不可被主角逐条操控。  
- **角色特性成长**：NPC 具有颜值、体型、资质、临时状态、兄弟姐妹关系等特性，且会随岁月变化（例如体型变化）。  
- **装备与法宝系统**：坊市可购买武器/护甲/符箓，并可炼器强化；还能开法宝匣获得法宝（战斗中主动释放）。  
- **成长称号**：角色会根据修为、声望、家族发展自动获得称号。  
- **家族系统（新增）**：可缔结道侣、生儿育女、培养子嗣、积累家族声望，形成代际成长线。  
- **传位继承**：支持将家业传给子嗣，以新一代家主继续游玩，实现“家族多世代修仙”。  
- **年度大事件**：每隔若干年会触发秘境、宗门大比、商路变化、妖潮等事件，带来机遇或风险。  
- **存档/读档**：支持 `savegame.json` 持久化，包含家族、装备、任务等进度。

## 目标与失败

- 修为达到 **1800**：踏入化神，游戏胜利。  
- 气血降至 **0**：角色陨落，游戏失败。
