# 修仙模拟人生文字游戏

一个轻量级命令行文字游戏：从凡人开始，通过修炼、历练、交易丹药提升修为，冲击更高境界。

## 直接下载游玩（打包）

### 1) 生成可下载压缩包

在项目根目录执行：

```bash
python3 build_package.py
```

执行后会生成：

- `dist/xianxia-game.zip`（可直接发给别人下载）
- `dist/xianxia-game/`（解压后的同内容目录）

### 2) 解压后启动

- macOS / Linux：双击或运行 `start.sh`
- Windows：双击 `start.bat`

> 需要本机已安装 Python 3。

## 开发环境运行

```bash
python3 game.py
```

## 玩法说明

每一回合可以选择：

1. **打坐修炼**：稳定提升修为，但会消耗少量气血。
2. **外出历练**：随机事件，可能获得收益，也可能受伤。
3. **坊市购丹**：消耗 10 灵石恢复气血。
4. **查看状态**：查看当前属性。
5. **结束游戏**。

## 胜负条件

- 修为达到 1600：踏入化神，游戏胜利。
- 气血降为 0：角色陨落，游戏失败。
